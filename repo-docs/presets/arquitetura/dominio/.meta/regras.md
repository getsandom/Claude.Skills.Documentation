# Regras: domínio

- **Identificador:** nenhum
- **Modelo:** [modelo.md](modelo.md)
- **Nome do arquivo:** o termo de negócio da entidade, como no glossário, quando houver (ex.: `entrega.md`)
- **Descrição no índice:** o que a entidade representa e suas regras principais
- **Ao encerrar:** remover o arquivo quando a entidade deixar de existir e registrar no histórico; não há seção Encerrados
- **Subtópicos:** nenhum

## O que registrar

Cada entidade do domínio exatamente como existe no código. Tipos de valor e uniões
que pertencem à entidade ficam no mesmo arquivo.

## Ciclo de vida

- Uma entidade por arquivo.
- O documento reflete o código. Mudanças planejadas não entram aqui.
- Se o documento e o código divergirem, corrija o documento ou abra uma pendência
  para revisá-lo.
