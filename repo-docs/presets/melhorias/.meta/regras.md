# Regras: melhorias

- **Identificador:** `MEL_NNN`
- **Modelo:** [modelo.md](modelo.md)
- **Nome do arquivo:** `MEL_NNN-titulo-curto.md` (ex.: `MEL_001-macros-no-corpo.md`)
- **Descrição no índice:** o que a melhoria entrega e o status
- **Ao encerrar:** remover o arquivo e mover a linha para a seção Encerrados do índice, com o desfecho Implementada ou Descartada
- **Subtópicos:** nenhum

## O que registrar

Uma melhoria é uma proposta de funcionalidade ou evolução fora do escopo atual, que
vale registrar para não se perder. Necessidades que o sistema deve atender são
requisitos; escolhas já feitas são decisões.

## Ciclo de vida

- Edite a proposta conforme ela amadurece, atualizando o status (Proposta, Aprovada,
  Em implementação).
- Quando for implementada, o comportamento passa a ser descrito na arquitetura (e
  nas decisões, se envolveu escolhas) e o arquivo é removido.
- Quando for descartada, o arquivo também é removido.
- Nos dois casos, mova a linha dela para a seção Encerrados do índice e registre no
  histórico com o motivo.
