# Requisitos

Necessidades que {{PROJETO}} deve atender, descritas em alto nível: dizem **o quê**,
não **como**; o como fica nas decisões e na arquitetura. Dividem-se em requisitos de
usuário, em linguagem de negócio, e requisitos de sistema, mais precisos, que
detalham os de usuário.

## Por onde começar

- [usuario/](usuario/): necessidades de quem usa o sistema.
- [sistema/](sistema/): o que o sistema deve fazer ou respeitar para atendê-las.

A lista completa fica no [índice](.meta/index.md); a rastreabilidade entre os dois
subtópicos está nas [regras do tópico](.meta/regras.md).
