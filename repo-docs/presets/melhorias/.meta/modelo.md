# Modelo de melhoria

```markdown
# MEL_NNN: Título

- **Status:** Proposta | Aprovada | Em implementação
- **Origem:** onde surgiu (sessão de DD/MM/AAAA, pedido de cliente, requisito)
- **Atualizado em:** DD/MM/AAAA
- **Relacionados:** links para decisões, pendências e outras melhorias

## Resumo

Uma ou duas frases sobre o que a melhoria entrega.

## Motivação

O problema ou a necessidade que ela resolve, e para quem.

## Proposta

Como poderia funcionar, no nível de detalhe que se tem hoje.

## Impacto

- Contratos públicos
- Modelo de dados
- Compatibilidade com quem já usa o sistema

## Dependências

O que precisa existir ou ser decidido antes.

## Questões em aberto

Perguntas a responder antes de aprovar.
```
