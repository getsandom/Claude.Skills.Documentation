# Support guide template

```markdown
# Subject

- **Updated:** YYYY-MM-DD

## Goal

What the guide allows you to do and for whom.

## Prerequisites

What must exist beforehand: permissions, tools, settings.

## Procedure

Numbered steps, with commands in code blocks and, per execution mode or platform,
their own subsections when the steps differ.

## Verification

How to confirm that the procedure worked.

## Common problems

Symptom, cause and solution of the known problems.

## References

- Related decisions, architecture and scripts (links)
```
