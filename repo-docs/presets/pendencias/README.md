# Pendências

O que precisa ser resolvido em {{PROJETO}} e ainda não foi: decisões em aberto,
defeitos conhecidos e débitos técnicos. Cada pendência guarda as opções levantadas,
para que o tópico não seja esquecido nem decidido sem considerá-las.

## Por onde começar

Ainda não há pendências abertas. A lista completa fica no [índice](.meta/index.md);
as já resolvidas ficam em [resolvidas/](resolvidas/), com a resolução. Como abrir e
resolver uma pendência está nas [regras do tópico](.meta/regras.md).
