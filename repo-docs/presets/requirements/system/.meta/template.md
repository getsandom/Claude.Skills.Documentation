# System requirement template

```markdown
# SRQ_NNN: Short title of the need

- **Priority:** Mandatory | Desirable | Optional
- **State:** Met | Partial | Not met
- **Updated:** YYYY-MM-DD
- **Details:** links to the user requirements
- **Met by:** links to decisions and architecture documents

## Description

The need in one or a few sentences, in the format "The system must...".

## Rationale

Why the need exists.

## Acceptance criteria

How to verify that the requirement is met.

## Notes

Known limitations, doubts or links to issues and improvements.
```
