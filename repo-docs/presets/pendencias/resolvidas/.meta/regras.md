# Regras: pendências resolvidas

- **Identificador:** `PEN_NNN` (compartilha a numeração de `pendencias/`)
- **Modelo:** o mesmo das pendências, em [../../.meta/modelo.md](../../.meta/modelo.md)
- **Nome do arquivo:** o mesmo que a pendência tinha em `pendencias/`
- **Descrição no índice:** começa por "Resolvida em DD/MM/AAAA.", seguida de uma lembrança do conteúdo e de para onde o resultado foi, com link para o destino quando houver
- **Ao encerrar:** não se aplica; pendências resolvidas não são removidas
- **Subtópicos:** nenhum

## O que registrar

Apenas pendências que vieram de `pendencias/` com status Resolvida e a seção
Resolução preenchida. Nenhum documento é criado diretamente aqui.

## Ciclo de vida

- O arquivo chega aqui movido de `pendencias/`, com os links relativos corrigidos.
- O conteúdo da discussão é mantido como estava; correções posteriores se limitam a
  links e à seção Resolução.
- Se o assunto voltar a exigir atenção, abra uma nova pendência com novo
  identificador e link para a resolvida.
