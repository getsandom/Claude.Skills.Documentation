# Rules: system requirements

- **Identifier:** `SRQ_NNN`
- **Template:** [template.md](template.md)
- **File name:** `SRQ_NNN-short-title.md` (e.g. `SRQ_003-retries.md`)
- **Index description:** the need, the priority and the state
- **On closing:** remove the file and move the line to the Closed section of the index, with the outcome Removed
- **Subtopics:** none

## What to record

What the system must do or comply with, in a verifiable way, to meet one or more
user requirements. The traceability and state rules are in the
[requirements rules](../../.meta/rules.md).

## Lifecycle

- When creating it, list the user requirements in **Details** and add this
  requirement to **Detailed by** in each of them.
- Edit the requirement when the need changes, updating the state and the date.
- If it ceases to exist, remove the file, move its line to the Closed section of
  the index, remove it from **Detailed by** in the user requirements and record it
  in the history.
