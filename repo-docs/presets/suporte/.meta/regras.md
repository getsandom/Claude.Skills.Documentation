# Regras: suporte

- **Identificador:** nenhum
- **Modelo:** [modelo.md](modelo.md)
- **Nome do arquivo:** `assunto.md` (ex.: `implantacao.md`)
- **Descrição no índice:** o que o guia permite fazer e os pontos principais
- **Ao encerrar:** remover o arquivo quando o assunto deixar de existir e registrar no histórico; não há seção Encerrados
- **Subtópicos:** nenhum

## O que registrar

Como instalar, configurar e operar o sistema em um ambiente. Um assunto operacional
por arquivo.

## Ciclo de vida

- Atualize o guia sempre que a configuração, os comandos ou os scripts mudarem.
- Scripts citados ficam no tópico de scripts, quando existir, e são referenciados
  por link.
