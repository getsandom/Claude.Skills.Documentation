# Modelo de requisito de usuário

```markdown
# RQU_NNN: Título curto da necessidade

- **Prioridade:** Obrigatório | Desejável | Opcional
- **Estado:** Atendido | Parcial | Não atendido
- **Atualizado em:** DD/MM/AAAA
- **Detalhado por:** links para os requisitos de sistema
- **Atendido por:** links para decisões e documentos de arquitetura

## Descrição

A necessidade em uma ou poucas frases, no formato "Quem deve poder o quê, para quê".

## Justificativa

Por que a necessidade existe.

## Critérios de aceitação

Como verificar que o requisito foi atendido.

## Observações

Limitações conhecidas, dúvidas ou ligações com pendências e melhorias.
```
