# Regras: scripts

- **Identificador:** nenhum
- **Modelo:** nenhum
- **Nome do arquivo:** o nome usual da plataforma do script (ex.: `Register-EventSource.ps1`, `instalar.sh`)
- **Descrição no índice:** o que o script faz, os parâmetros principais e onde o uso é descrito
- **Ao encerrar:** remover o arquivo quando nenhum guia o citar mais e registrar no histórico; não há seção Encerrados
- **Subtópicos:** nenhum

## O que registrar

Scripts de instalação e operação citados pelos guias de suporte. Scripts de
desenvolvimento ou de build ficam no código, fora desta pasta.

## Ciclo de vida

- Todo script é citado por ao menos um guia de suporte, que descreve o uso.
- O cabeçalho do script descreve o que ele faz e seus parâmetros.
- Ao alterar parâmetros ou comportamento, atualize o guia que o cita.
