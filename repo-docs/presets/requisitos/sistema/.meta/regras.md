# Regras: requisitos de sistema

- **Identificador:** `RQS_NNN`
- **Modelo:** [modelo.md](modelo.md)
- **Nome do arquivo:** `RQS_NNN-titulo-curto.md` (ex.: `RQS_003-retentativas.md`)
- **Descrição no índice:** a necessidade, a prioridade e o estado
- **Ao encerrar:** remover o arquivo e mover a linha para a seção Encerrados do índice, com o desfecho Removido
- **Subtópicos:** nenhum

## O que registrar

O que o sistema deve fazer ou respeitar, de forma verificável, para atender um ou
mais requisitos de usuário. As regras de rastreabilidade e de estado estão nas
[regras de requisitos](../../.meta/regras.md).

## Ciclo de vida

- Ao criar, liste os requisitos de usuário em **Detalha** e acrescente este
  requisito em **Detalhado por** em cada um deles.
- Edite o requisito quando a necessidade mudar, atualizando o estado e a data.
- Se deixar de existir, remova o arquivo, mova a linha dele para a seção Encerrados
  do índice, retire-o de **Detalhado por** nos requisitos de usuário e registre no
  histórico.
