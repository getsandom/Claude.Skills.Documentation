# History

Summary record of the decisions and actions taken in the documentation of {{PROJECT}}:
what was created, changed or removed, when and why. It allows the other documents
to describe only the current state; detailed change tracking is left to git.

## Where to start

One file per day with changes, in chronological order. The full list is in the
[index](.meta/index.md); the format is in the [topic rules](.meta/rules.md).
