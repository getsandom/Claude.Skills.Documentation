# Modelo de guia de suporte

```markdown
# Assunto

- **Atualizado em:** DD/MM/AAAA

## Objetivo

O que o guia permite fazer e para quem.

## Pré-requisitos

O que precisa existir antes: permissões, ferramentas, configurações.

## Procedimento

Passos numerados, com comandos em blocos de código e, por modo de execução ou
plataforma, subseções próprias quando os passos diferirem.

## Verificação

Como confirmar que o procedimento funcionou.

## Problemas comuns

Sintoma, causa e solução dos problemas conhecidos.

## Referências

- Decisões, arquitetura e scripts relacionados (links)
```
