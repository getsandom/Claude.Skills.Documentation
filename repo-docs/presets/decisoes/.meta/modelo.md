# Modelo de decisão

```markdown
# DEC_NNN: Título no formato de afirmação

- **Atualizado em:** DD/MM/AAAA
- **Relacionados:** links para decisões, pendências, melhorias e arquitetura

## Contexto

O problema ou a pergunta que exigiu a decisão, e as restrições relevantes.
Escrito para quem não participou da discussão.

## Decisão

O que foi decidido, de forma direta e verificável. Regras concretas (códigos,
limites, nomes) em lista.

## Alternativas consideradas

- **Alternativa A:** em uma ou duas frases, e por que foi descartada.
- **Alternativa B:** ...

## Consequências

- O que passa a ser verdade ou obrigatório no sistema.
- Custos, riscos e limitações aceitos.
- Trabalho que a decisão gera (com link para pendências, se houver).
```
