# Issue template

```markdown
# ISS_NNN: Title phrased as a question or problem

- **Type:** Open decision | Defect | Technical debt
- **Status:** Open | Under discussion | Resolved
- **Updated:** YYYY-MM-DD
- **Related:** links to decisions, improvements and architecture

## Description

What is pending and what the effect of not resolving it is.

## Why it is open

What prevents the resolution today (lack of information, depends on another subject, priority).

## Options on the table

For open decisions. No option raised leaves the list without a record of the reason.

### Option A: name
Description, pros and cons.

### Option B: name
...

## Decision criteria

What should weigh in the choice (security, performance, user experience...).

## Items

For defects and technical debts: what needs to be fixed, with the file and the
effect of each item.

## Resolution

Not resolved yet.
```
