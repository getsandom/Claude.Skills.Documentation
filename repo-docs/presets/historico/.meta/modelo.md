# Modelo de histórico

```markdown
# DD/MM/AAAA

## HH:MM: resumo curto da mudança

- **Tipo:** Criação | Alteração | Remoção
- **Documentos:** links para os arquivos afetados, com o identificador quando houver
  (para arquivos removidos, o caminho em texto, ex.: `decisoes/DEC_002-titulo.md`)
- **Motivo:** por que mudou, em uma ou duas frases
- **Referência:** opcional; commit, PR, sessão ou reunião de origem
```
