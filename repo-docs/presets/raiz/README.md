# Documentação de {{PROJETO}}

Esta pasta descreve como {{PROJETO}} funciona hoje, por que ele é assim e o que ainda
está em aberto. Ela é a fonte de verdade de requisitos, decisões e pendências do
projeto, versionada junto com o código.

## Como navegar

- A lista dos tópicos, com o que cada um reúne, está no [índice](.meta/index.md).
- As regras que valem para todos os tópicos (identificadores, índices, histórico,
  convenções) estão nas [regras gerais](.meta/regras.md).
- Cada tópico é uma pasta com um `README.md` de apresentação, os documentos de
  conteúdo e uma subpasta `.meta/` com o índice, as regras e, quando houver, o modelo
  dos documentos do tópico.

Antes de criar ou alterar um documento, leia as regras gerais e as regras do tópico.
