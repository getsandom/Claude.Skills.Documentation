# Rules: resolved issues

- **Identifier:** `ISS_NNN` (shares the numbering of `issues/`)
- **Template:** the same as the issues, in [../../.meta/template.md](../../.meta/template.md)
- **File name:** the same name the issue had in `issues/`
- **Index description:** starts with "Resolved on YYYY-MM-DD.", followed by a reminder of the content and of where the result went, with a link to the destination when there is one
- **On closing:** not applicable; resolved issues are not removed
- **Subtopics:** none

## What to record

Only issues that came from `issues/` with the status Resolved and the Resolution
section filled in. No document is created directly here.

## Lifecycle

- The file arrives here moved from `issues/`, with its relative links fixed.
- The content of the discussion is kept as it was; later corrections are limited to
  links and to the Resolution section.
- If the subject needs attention again, open a new issue with a new identifier and
  a link to the resolved one.
