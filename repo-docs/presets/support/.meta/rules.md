# Rules: support

- **Identifier:** none
- **Template:** [template.md](template.md)
- **File name:** `subject.md` (e.g. `deployment.md`)
- **Index description:** what the guide allows you to do and its main points
- **On closing:** remove the file when the subject ceases to exist and record it in the history; there is no Closed section
- **Subtopics:** none

## What to record

How to install, configure and operate the system in an environment. One operational
subject per file.

## Lifecycle

- Update the guide whenever the configuration, the commands or the scripts change.
- Cited scripts live in the scripts topic, when it exists, and are referenced by
  link.
