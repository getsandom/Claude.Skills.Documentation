# Domain entity template

```markdown
# Business term (`ClassName`)

- **Code:** project, module or package
- **Updated:** YYYY-MM-DD

## Description

What the entity represents.

## Attributes

| Attribute | Type | Required | Description |
|---|---|---|---|

## Value types

Unions and value objects of the entity, with their variants and validations.

## Relationships

Which entities it relates to and with what cardinality.

## Rules and invariants

Creation, state transitions, validations.

## Persistence

Table, keys, global filters, field encryption and relevant mappings.

## References

- Related decisions, requirements and issues (links)
- Code: paths of the main files
```
