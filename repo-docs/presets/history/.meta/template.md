# History template

```markdown
# YYYY-MM-DD

## HH:MM: short summary of the change

- **Type:** Creation | Change | Removal
- **Documents:** links to the affected files, with the identifier when there is one
  (for removed files, the path as text, e.g. `decisions/DEC_002-title.md`)
- **Reason:** why it changed, in one or two sentences
- **Reference:** optional; originating commit, PR, session or meeting
```
