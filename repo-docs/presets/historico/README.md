# Histórico

Registro resumido das decisões e ações tomadas na documentação de {{PROJETO}}: o que
foi criado, alterado ou removido, quando e por quê. Ele permite que os demais
documentos descrevam apenas o estado atual; o controle detalhado de alterações fica
com o git.

## Por onde começar

Um arquivo por dia com alterações, em ordem cronológica. A lista completa fica no
[índice](.meta/index.md); o formato está nas [regras do tópico](.meta/regras.md).
