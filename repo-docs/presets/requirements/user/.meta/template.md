# User requirement template

```markdown
# URQ_NNN: Short title of the need

- **Priority:** Mandatory | Desirable | Optional
- **State:** Met | Partial | Not met
- **Updated:** YYYY-MM-DD
- **Detailed by:** links to the system requirements
- **Met by:** links to decisions and architecture documents

## Description

The need in one or a few sentences, in the format "Who must be able to do what, and why".

## Rationale

Why the need exists.

## Acceptance criteria

How to verify that the requirement is met.

## Notes

Known limitations, doubts or links to issues and improvements.
```
