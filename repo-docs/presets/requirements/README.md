# Requirements

Needs that {{PROJECT}} must meet, described at a high level: they say **what**,
not **how**; the how lives in the decisions and in the architecture. They are
divided into user requirements, in business language, and system requirements,
more precise, which detail the user ones.

## Where to start

- [user/](user/): needs of those who use the system.
- [system/](system/): what the system must do or comply with to meet them.

The full list is in the [index](.meta/index.md); the traceability between the two
subtopics is in the [topic rules](.meta/rules.md).
