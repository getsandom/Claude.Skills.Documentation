# {{PROJECT}} documentation

This folder describes how {{PROJECT}} works today, why it is the way it is and what
is still open. It is the source of truth for the project's requirements, decisions
and issues, versioned together with the code.

## How to navigate

- The list of topics, with what each one gathers, is in the [index](.meta/index.md).
- The rules that apply to all topics (identifiers, indexes, history,
  conventions) are in the [general rules](.meta/rules.md).
- Each topic is a folder with an introductory `README.md`, the content documents
  and a `.meta/` subfolder with the index, the rules and, when there is one, the
  template for the topic's documents.

Before creating or changing a document, read the general rules and the topic rules.
