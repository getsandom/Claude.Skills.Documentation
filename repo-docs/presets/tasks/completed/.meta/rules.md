# Rules: completed tasks

- **Identifier:** `TSK_NNN` (shares the numbering of `tasks/`)
- **Template:** the same as the tasks, in [../../.meta/template.md](../../.meta/template.md)
- **File name:** the same name the task folder had in `tasks/`
- **Index description:** starts with "Completed on YYYY-MM-DD.", followed by a reminder of the goal and of where the result took effect, with a link when there is one
- **On closing:** not applicable; completed tasks are not removed
- **Subtopics:** one folder per completed task

## What to record

Only tasks that came from `tasks/` with the state Completed, all steps completed
and the Conclusion section filled in. No task is created directly here.

## Lifecycle

- The folder arrives here moved from `tasks/`, with its relative links fixed.
- The content is kept as it was; later corrections are limited to links.
- If the subject needs work again, open a new task with a new identifier and a
  link to the completed one.
