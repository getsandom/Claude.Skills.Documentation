# Improvement template

```markdown
# IMP_NNN: Title

- **Status:** Proposed | Approved | In implementation
- **Origin:** where it came from (session of YYYY-MM-DD, customer request, requirement)
- **Updated:** YYYY-MM-DD
- **Related:** links to decisions, issues and other improvements

## Summary

One or two sentences about what the improvement delivers.

## Motivation

The problem or need it solves, and for whom.

## Proposal

How it could work, at the level of detail available today.

## Impact

- Public contracts
- Data model
- Compatibility with those who already use the system

## Dependencies

What must exist or be decided first.

## Open questions

Questions to answer before approving.
```
