# Tasks

Extensive plans and executions of {{PROJECT}}, contiguous and carried out in sequence
by AI agents, that do not fit in a single change and must be able to stop and
continue, including on another machine. Each task is a folder with the presentation
of the scope and the proposal and one file per step, in execution order, with the
context, the blockers, the action, the limits, the success criterion, the handoff
and the conclusion.

The task executes what has already been decided: the problem lives in the issues,
and the choice, in the decisions or in the document where the result takes effect.

## Where to start

Before planning a task, check the size of the scope: if it foresees only one or two
steps, ask the user whether they really want to create the task, proposing an issue
instead. An issue only becomes a task at the user's explicit request. Ambiguities
are resolved by interviewing the user.
