# Regras: decisões

- **Identificador:** `DEC_NNN`
- **Modelo:** [modelo.md](modelo.md)
- **Nome do arquivo:** `DEC_NNN-titulo-curto.md` (ex.: `DEC_004-idempotencia.md`)
- **Descrição no índice:** o que foi decidido
- **Ao encerrar:** remover o arquivo e mover a linha para a seção Encerrados do índice, com o desfecho Revogada ou Substituída por `DEC_NNN`
- **Subtópicos:** nenhum

## O que registrar

Uma decisão registra uma escolha já tomada sobre o comportamento, o contrato ou a
estrutura do projeto, junto do motivo e do que foi descartado. Registre aqui apenas
o que foi efetivamente decidido: tópicos sem conclusão vão para as pendências; ideias
para o futuro, para as melhorias.

## Ciclo de vida

- Uma decisão por arquivo.
- Se a decisão mudar, edite o arquivo para refletir o que vale agora e registre a
  mudança no histórico.
- Se for revogada ou substituída, remova o arquivo, mova a linha dela para a seção
  Encerrados do índice e registre no histórico.
